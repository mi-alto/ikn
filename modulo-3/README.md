# Modulo 3 — Dividere un PDF con un agente

**Materiale:** [scarica l’estratto Enel di 6 pagine](../modulo-2/enel-estratto-esercitazione-2025.pdf).

1. In LibreChat, apri l’Agent Builder, crea un agente e abilita **Run Code**, se disponibile.
2. Apri una chat con l’agente, allega il PDF e chiedi: «Scrivi ed esegui un programma Python che divida il PDF allegato dopo la terza pagina. Restituisci i due PDF e verifica il numero e l’ordine delle pagine».
3. Scarica i risultati. Il primo PDF deve contenere le pagine 1–3 dell’estratto, il secondo le pagine 4–6.
4. Se l’esecuzione del codice non è disponibile, chiedi lo script e fai indicare all’agente la libreria necessaria per eseguirlo.

Per la parte su skill e MCP usa le funzionalità abilitate dal docente nell’istanza del corso. Le skill da consultare sono nel [repository Financial Services di Anthropic](https://github.com/anthropics/financial-services).
