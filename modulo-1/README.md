# Modulo 1 — Chiavi API per le esercitazioni

Accedi alla piattaforma del fornitore, crea una chiave API personale e seleziona un modello incluso nell’offerta gratuita disponibile per il tuo account.

| Piattaforma | Dove creare la chiave | Come usare l’offerta gratuita |
|---|---|---|
| Google Gemini | [Google AI Studio — API keys](https://aistudio.google.com/apikey) | Usa un progetto Free Tier e un modello incluso nel [listino Gemini](https://ai.google.dev/gemini-api/docs/pricing). |
| Z.ai | [Z.ai — API Keys](https://z.ai/manage-apikey/apikey-list) | Crea una Standard API Key. Il [listino Z.ai](https://docs.z.ai/guides/overview/pricing) indica GLM-4.7-Flash come gratuito. |
| Mistral AI | [Mistral Studio — API Keys](https://console.mistral.ai/api-keys/) | Usa il piano API gratuito se disponibile per il tuo account. Segui la [guida di Mistral Studio](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key). |

Conserva la chiave in un posto sicuro. Evita di condividerla nella chat del corso o di caricarla su GitHub.
